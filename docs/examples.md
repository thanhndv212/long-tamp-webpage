# Examples

LongTAMP’s examples cover progressively larger integration surfaces.

| Example | What it demonstrates |
| --- | --- |
| `script/twin/task_lift_ball.py` | Minimal bimanual scene and coordinated lift |
| `script/templates/` | A reusable YAML and Python starting point |
| `script/screw_assembly/` | Long-horizon multi-phase assembly and recovery |
| `examples/behaviortree/` | Standalone BehaviorTree.CPP host with embedded Python |

Start with the twin example to validate installation and visualization. Move to the task template when introducing a new robot or scene. Use the screw-assembly and behavior-tree examples when the mission needs phase recovery, checkpoints, or a separate execution layer.
