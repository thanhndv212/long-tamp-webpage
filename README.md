# LongTAMP website

Documentation and project website for [LongTAMP](https://github.com/thanhndv212/long-tamp), built with Docusaurus.

The deployed site lives at [thanhndv212.github.io/long-tamp-webpage](https://thanhndv212.github.io/long-tamp-webpage/).

```bash
npm install
npm start
```

Create a production build with `npm run build`. The GitHub Actions workflow publishes the site to GitHub Pages after pushes to `main`.
